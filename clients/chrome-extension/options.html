VAGG SAML Relay — Configuração

Configure a URL do VAGG core. A extensão usa essas credenciais pra fazer o relay SAML quando o gateway VPN redirecionar pra 127.0.0.1:8020 após o login Microsoft.

Ex: http://192.168.68.102 ou https://vagg.minhaempresa.com

Token JWT do admin. Pegue após login no painel via DevTools: localStorage.getItem('vagg.access_token').
